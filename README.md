# Business Lab — «Обери своє рішення»

Навчальна онлайн-гра факультету бізнесу, технологій та економіки.
Гравець вводить ім'я, бачить 10 карток, відкриває будь-яку, обирає один із трьох варіантів відповіді й одразу отримує пояснення. Після 10 карток — підсумок і рейтинг студентів.

## Як запустити

- **Найпростіше:** відкрийте `index.html` у браузері (подвійний клік).
- **У Visual Studio Code:** встановіть розширення **Live Server**, натисніть правою кнопкою на `index.html` → **Open with Live Server**.

## Структура

```
index.html        — розмітка: старт, поле карток, вікно завдання, результат + рейтинг
css/style.css     — дизайн («біржовий термінал»)
js/questions.js   — банк питань (60 = 6 кафедр × 10) і налаштування гри
js/app.js         — логіка: рандом карток, бали, таймер, рейтинг
```

## Як змінити питання

Усе редагується в `js/questions.js`:

- `DEPARTMENTS` — назви кафедр, короткі коди та кольори карток.
- `QUESTIONS` — питання. У кожного: `dept` (код кафедри), `question`, `options` (рівно 3), `correct` (0 = A, 1 = B, 2 = C), `explanation`.
- `GAME_CONFIG`:
  - `cardsPerGame` — скільки карток у грі (10);
  - `balancedByDepartment` — `true`: у кожній грі є хоча б одне питання з кожної кафедри, решта — випадкові; `false`: повністю випадкові 10 із 60;
  - `shuffleOptions` — перемішувати варіанти A/B/C.

## Правила підрахунку

- Правильна відповідь — 1 бал, неправильна — 0. Максимум — 10.
- Після підтвердження відповідь змінити не можна.
- Рейтинг: більше балів — вище; за однакових балів вище той, хто пройшов швидше.

## Про рейтинг

Зараз результати зберігаються в браузері (`localStorage`) — рейтинг спільний для всіх, хто грає **на одному комп'ютері/в одному браузері** (зручно для захисту проєкту). Щоб об'єднати результати з різних пристроїв, наступним кроком можна підключити спільну базу даних (наприклад, Firebase або Supabase).
