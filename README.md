# Business Lab — «Обери своє рішення»

Навчальна онлайн-гра факультету бізнесу, технологій та економіки.
Гравець вводить ім'я, бачить 10 карток, відкриває будь-яку, обирає один із трьох варіантів відповіді й одразу отримує пояснення. Після 10 карток — підсумок і рейтинг студентів.

## Як запустити

- **Найпростіше:** відкрийте `index.html` у браузері (подвійний клік).
- **У Visual Studio Code:** встановіть розширення **Live Server**, натисніть правою кнопкою на `index.html` → **Open with Live Server**.

## Структура проєкту

```
index.html                 — розмітка: старт, поле карток, вікно завдання, результат + рейтинг

css/
  base.css                 — кольори, шрифт Poppins, декоративні шестикутники
  layout.css               — хедер з кафедрами, меню, екрани, футер
  components.css           — двоколірні заголовки, «пілюлі», кнопки, шестикутні рамки
  start.css                — стартовий екран
  board.css                — поле карток-«стільників»
  modal.css                — вікно завдання (зелений/червоний, пояснення)
  results.css              — підсумок і таблиця рейтингу
  responsive.css           — адаптивність під телефони

js/
  config.js                — налаштування гри та список кафедр (назви, кольори)
  questions/               — банк питань: 1 файл = 1 кафедра, по 10 питань
    economics.js  finance.js  marketing.js
    management.js it.js       accounting.js
  core/
    utils.js               — допоміжні функції (перемішування, час…)
    leaderboard.js         — збереження та сортування рейтингу
    game.js                — правила: вибір 10 із 60, бали, завершення
  ui/
    screens.js             — перемикання екранів, кафедри в хедері, меню
    board.js               — шестикутні картки, розкладка, лічильники, таймер
    modal.js               — питання, вибір і перевірка відповіді
    results.js             — підсумок і рейтинг
  main.js                  — запуск гри та обробники кнопок
```

## Дизайн

Оформлення повторює презентацію проєкту: білий фон, синій `#1A1AD4` і жовтий `#FFC700`, шестикутники, шрифт Poppins, двоколірні заголовки (верхній рядок синій, нижній жовтий) і хедер-«пілюля». Кафедри факультету показуються в хедері, а на вузьких екранах — у меню (≡).

**Фото на головній:** покладіть свою картинку у файл `img/hero.jpg` — вона з'явиться в шестикутнику замість ілюстрації.

Команду, керівника та університет можна змінити у футері в `index.html`.

## Як змінити питання

Питання кожної кафедри лежать в окремому файлі в `js/questions/`. Формат одного питання:

```js
{
  question: "Текст питання",
  options: ["Варіант A", "Варіант B", "Варіант C"],
  correct: 1,                       // 0 = A, 1 = B, 2 = C
  explanation: "Пояснення після відповіді"
}
```

Назви кафедр, їхні кольори та налаштування — у `js/config.js`:

- `cardsPerGame` — скільки карток у грі (10);
- `balancedByDepartment` — `true`: у кожній грі є хоча б одне питання з кожної кафедри, решта випадкові; `false`: повністю випадкові 10 із 60;
- `shuffleOptions` — перемішувати варіанти A/B/C.

Щоб додати нову кафедру: допишіть її в `BL.departments`, створіть файл у `js/questions/` і підключіть його в `index.html`.

## Правила підрахунку

- Правильна відповідь — 1 бал, неправильна — 0. Максимум — 10.
- Після підтвердження відповідь змінити не можна.
- Рейтинг: більше балів — вище; за однакових балів вище той, хто пройшов швидше.

## Про рейтинг

Зараз результати зберігаються в браузері (`localStorage`) — рейтинг спільний для всіх, хто грає **на одному комп'ютері/в одному браузері** (зручно для захисту проєкту). Щоб об'єднати результати з різних пристроїв, наступним кроком можна підключити спільну базу даних (наприклад, Firebase або Supabase) — для цього достатньо переписати лише `js/core/leaderboard.js`.
