# BUSINESS LAB

Навчальна онлайн-гра Факультету бізнес-технологій та економіки. Гравець вводить ПІБ, бачить 10 карток шести кафедр, відкриває будь-яку, обирає одну з трьох відповідей і одразу бачить пояснення. Після 10 карток показуються підсумок і рейтинг.

## Як запустити

- Відкрийте `index.html` у браузері (подвійний клік).
- Або у VS Code: розширення **Live Server**, ПКМ на `index.html` → **Open with Live Server**.

## Структура

```
index.html            розмітка: старт, поле карток, вікно питання, результат і рейтинг
css/style.css         стилі; світла тема за замовчуванням, темна через перемикач у хедері
js/config.js          простір імен BL і функція додавання питань
js/questions/*.js     банк питань: 1 файл = 1 кафедра, по 10 питань (усього 60)
js/app.js             логіка гри: картки, таймер, підрахунок, рейтинг, тема, біжучий рядок факультетів
```

## Кафедри (код у файлах → кафедра)

| Файл | Код | Кафедра |
|---|---|---|
| marketing.js | mkt | МЛ, Маркетинг і логістика |
| management.js | mgt | МА, Менеджмент та адміністрування |
| accounting.js | acc | ОФ, Облік та фінанси |
| finance.js | fin | БУ, Бізнес та управління |
| it.js | it | ЦТ, Цифрові технології в бізнесі та економіці |
| economics.js | econ | ЕМС, Економіка та митна справа |

Назви, абревіатури, описи й кольори кафедр задаються в `js/app.js` (об'єкт `DEPTS`), а список факультетів для біжучого рядка там же (`FACULTIES`). Кольори кафедр і теми лежать у `css/style.css` (змінні `--d-*`).

## Формат питання

```js
{
  question: "Текст питання",
  options: ["Варіант A", "Варіант B", "Варіант C"],
  correct: 1,                 // 0 = A, 1 = B, 2 = C
  explanation: "Пояснення після відповіді"
}
```

## Правила підрахунку

- Правильна відповідь дає 1 бал, неправильна 0. Максимум 10.
- Після підтвердження відповідь змінити не можна.
- У рейтингу вище той, хто має більше балів, а за рівних балів той, хто пройшов швидше.
- Кожна гра містить щонайменше одне питання з кожної кафедри, решта картки випадкові.

## Рейтинг

В онлайн-версії (Claude Artifact) рейтинг спільний для всіх гравців і зберігається в базі артефакту. Якщо відкрити `index.html` локально, рейтинг зберігається в `localStorage` цього браузера, тобто він спільний для всіх, хто грає на одному комп'ютері. Щоб зробити спільний рейтинг на власному хостингу, потрібно замінити функції `saveResult` та `initStore` у `js/app.js` на роботу з базою (наприклад, Firebase або Supabase).
